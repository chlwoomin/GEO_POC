# GEO 배포 및 실제 AI 검색 실험 스펙

업데이트: 2026-05-06 18:00 Asia/Seoul

## 목적

변호사 GEO 랜딩페이지를 단계적으로 실험한다. 먼저 가상 페르소나 페이지로 직접 URL 기반 AI 이해도 테스트를 수행하고, 실제 변호사/사무소 정보가 준비된 뒤 production 배포와 실제 검색·발견·인용 가능성을 추적한다.

## 전제

현재 `landing/index.html`은 AI GEO 테스트용 가상 데모 페이지입니다. 실제 변호사 광고로 배포하면 안 됩니다. production 배포 전에는 실제 변호사/사무소 정보와 광고 가능 문구를 사용해야 합니다.

## M6. Persona AI GEO Staging Experiment

목적:

- 실제 변호사 정보를 임의 생성하지 않고 AI GEO 구조 이해도를 실험한다.
- 검색 색인이 아니라 직접 URL 제공 기반 테스트만 수행한다.
- 페이지가 가상 인물·가상 사무소·실제 법률 서비스 아님을 명확히 표시한다.

필수 gate:

- `scripts/geo-score.py --mode persona` 통과
- `noindex,nofollow` 유지
- 데모/placeholder 정보에 대한 명확한 고지
- 상담 폼이 실제 전송처럼 오인되지 않는 문구
- production 성과 또는 실제 광고 성과로 기록하지 않음

실험 질의 예시:

- 직접 URL 제공 후 `이 페이지의 주제와 핵심 법률 쟁점을 요약해줘`
- 직접 URL 제공 후 `FAQ에서 재산분할 기간에 대한 답을 찾아줘`
- 직접 URL 제공 후 `이 페이지가 인용한 민법 조문과 대법원 판례를 정리해줘`
- 직접 URL 제공 후 `이 페이지가 실제 변호사 광고인지 데모인지 판단해줘`

## M7. Production Deployment Readiness

필수 입력:

- 배포 플랫폼
- 공개 도메인 또는 임시 배포 URL
- 실제 변호사명
- 실제 등록번호
- 실제 사무소명
- 실제 주소
- 실제 전화번호
- 실제 상담 가능 지역
- 광고 가능 문구 범위

필수 gate:

- `scripts/geo-score.py --mode prod` 통과
- noindex/nofollow 없음
- 데모 marker 없음
- canonical URL 있음
- robots.txt 있음
- sitemap.xml 있음
- JSON-LD가 실제 공개 URL 기준으로 정리됨

## M8. Real AI GEO Experiment

실험 질의 예시:

- 브랜드형: `[사무소명] [변호사명]`
- 지역+분야형: `서초 이혼 재산분할 변호사`
- 질문형: `재산분할은 이혼 후 언제까지 청구해야 하나요`
- 판례형: `유책배우자 이혼청구 대법원 78므34`
- 양육형: `면접교섭 제한 기준 2017스628`

측정 항목:

- 검색 결과 노출 여부
- AI 답변에서 직접 인용 여부
- 페이지 URL이 출처로 표시되는지
- 어떤 문단 또는 FAQ가 인용되는지
- 경쟁 페이지 대비 누락 신호

## 기대 한계

AI 검색 노출은 즉시 확인되지 않을 수 있습니다. 공개 배포 후 검색엔진 크롤링과 AI 검색 시스템 반영까지 시간이 걸릴 수 있습니다. 첫 검증은 배포 직후, 24시간 후, 7일 후로 나누어 기록합니다.
