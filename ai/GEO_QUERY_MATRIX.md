# AI GEO Query Matrix

업데이트: 2026-05-06 20:20 Asia/Seoul

## 목적

M8에서 공개 URL이 준비된 뒤 AI 검색·요약·인용 여부를 반복 측정하기 위한 질의표입니다. 현재는 랜딩 초안 검증용 matrix이며, 실제 검색 노출 성과로 기록하지 않습니다.

## 테스트 전 조건

- 공개 URL 접근 가능
- `robots.txt`와 `sitemap.xml` 접근 가능
- canonical URL이 공개 URL과 일치
- `scripts/geo-score.py --mode prod` 통과
- 김재철 변호사님/백상 법무법인 실제 등록번호·주소·전화번호 확인 완료
